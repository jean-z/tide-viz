# 潮汐之舞 · Tide Dance

全球潮汐可视化：**M2/S2/K1/O1 四大分潮**合成的潮高场实时演化，
潮流粒子在球面上流动，六大港口实时潮位读数。

"太空科普系列"第八弹。与「风之镜」共享球面渲染引擎（2D Canvas 正交投影），
组成"风 + 潮"海洋双件套。

## 运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev     # → http://localhost:5180
npm test        # 潮汐层回归测试（7 项，Node 直接跑）
```

## 你能看到什么

- **潮流粒子流**：潮高梯度的旋转流场（地转平衡直观近似），在陆架海区流速明显增强
- **潮高读数**：宁波-舟山/青岛/旧金山/伦敦/悉尼/新加坡六港实时涨落数值（演示量级 ±4m）
- **潮型**：各港标注半日潮/混合潮/全日潮型
- **大潮-小潮**：M2 与 S2 的拍频（14.77 天朔望周期）实时显示当前潮相
- **海盆形态**：东海陆架/芬迪湾/西北澳等强潮区放大，地中海/波罗的海微潮
- 无潮点旋涡：潮波绕五个主要无潮点旋转（相位扭转）

## 物理内核（真实的部分）

- 四大分潮**周期为 Doodson 标准值**（M2=12.4206h 等），大潮周期 353.9h 精确复现
- 半日潮港一天两次高潮、朔望拍频——测试断言全部通过（`npm test`）
- 潮流 = 潮高梯度旋转 90°（北半球地转流向右偏转的直观体现）

## 诚实边界（演示的部分）

振幅地理分布用**平衡潮 + 海盆近似**构造（陆架放大/半封闭衰减/无潮点旋涡），
形态学正确但不是数值预报；真实潮汐预报需 TPXO/FES 全球模型数据（v2 接入点
已预留：`tideHeight()` 是纯函数，换数据源零改动渲染层）。

## 架构
